# dreamdex-perps-feedback

Feedback, notes and helper scripts for the dreamDEX perps bounty.

## Layout

- `feedback/` — written feedback reports
- `scripts/` — helper scripts for testnet interaction
- `notes/` — working notes

## Setup

Put the testnet private key in a local `.env` file (`TESTNET_PRIVATE_KEY=`). `.env` is gitignored and must never be committed.
